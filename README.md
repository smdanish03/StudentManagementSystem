# Student Management System

A **Java console application** for managing student records. This project allows users to add, view, update, delete, search, and sort students by their marks.

## Features

- Add a new student with ID, name, and marks
- Display all student records
- Delete a student by ID
- Search for a student by ID
- Update a student's information
- Sort students based on marks and show toppers
- User-friendly console interface

## Technologies Used

- Java
- Scanner for input
- Object-Oriented Programming (OOP) principles
